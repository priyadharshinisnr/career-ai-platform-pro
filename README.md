# Career AI Platform Pro

## 📌 Project Overview

Career AI Platform Pro is a web-based career guidance platform designed to help students analyze their skills, explore suitable career paths, build learning roadmaps, and understand their career progress.

The platform provides separate modules for students and administrators to make career planning more organized and accessible.

## ✨ Features

- 👤 Student Registration and Login
- 🎯 Career Goal Selection
- 🧠 AI-Based Skill Analysis
- 📊 Skill Progress Tracking
- 💼 Career Recommendations
- 📝 Resume Analyzer
- 🗺️ Personalized Learning Roadmap
- 📈 Student and Career Reports
- 🔐 Admin Dashboard
- 👨‍🎓 Student Management

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Git & GitHub
- Netlify

## ⚙️ How It Works

1. Students register and log in to the platform.
2. Students select their career goal and domain.
3. The platform analyzes the provided skills.
4. Career recommendations are displayed.
5. Students can view their skill progress.
6. Students can access a personalized learning roadmap.
7. The Resume Analyzer helps students review their skills and career role.
8. Administrators can manage students and view reports.
